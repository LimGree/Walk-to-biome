# GridOccupancy

**Файл:** `Assets/Script/Core/Systems/GridOccupancy.cs`  
**Тип:** статический словарь «клетка → объект»

## Зачем нужен

Отвечает на вопрос: «здесь уже кто-то стоит?»

- `Register` / `Unregister`
- `GetAt(клетка)`
- `CollectAllOccupiedObjects` — для карты (нарисовать здания пикселями) и для исследования карты (открыть клетки под фабрикой)

При загрузке мира сначала всё чистят, потом здания регистрируются заново.
