# TutorialUI

**Файл:** `Assets/Script/Core/Tutorial/TutorialUI.cs`

Панель шага 0 и 16, цель в углу. Пропуск на панелях кнопкой, во время игры — **F1** (курсор залочен, кнопку не нажать). Подсвечивает карточки/кнопки классом `tut-glow`.

На модалке курсор свободен, пауза не открывается ([[GameManager.BlocksPause]] через [[TutorialSystem]]).

Связи: [[TutorialSystem]] · [[InventoryUI]] · [[InputHintUI]] · [[UiLocale]]
