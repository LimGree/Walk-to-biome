# LoadingScreen

**Файл:** `Assets/Script/Core/UI/LoadingScreen.cs`  
**Тип:** компонент на сцене `Loading`

## Зачем нужен

Прокладка между меню и игрой: показывает «Загрузка…» и через кадр грузит `SampleScene`. Без этого Unity иногда рисует пустой кадр.

## Связи

[[MainMenu]] (кто грузит эту сцену), [[IndustryUi]], [[UiLocale]]

## Методы

### Start
Строит простой UI с текстом загрузки.

### LateUpdate
Один раз запускает загрузку игровой сцены. `started` не даёт грузить дважды.
