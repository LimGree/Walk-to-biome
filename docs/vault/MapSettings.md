# MapSettings

**Файл:** `Assets/Script/Core/Systems/MapSettings.cs`

PlayerPrefs миникарты и карты мира: круг/квадрат, угол экрана, зум, размер, прозрачность, компас, координаты, биом, сетка, голограммы, скрывать неисследованное, радиус исследования, **разрешать ли телепорт** (по умолчанию нет).

Событие `Changed` — [[WorldMapUI]] сразу перекладывает рамку.

Не путать с [[GameSettings]] (графика) и [[MapSettingsUI]] (рисует слайдеры).
