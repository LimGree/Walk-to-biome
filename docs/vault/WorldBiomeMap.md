# WorldBiomeMap

**Файл:** `Assets/Script/Core/Systems/WorldBiomeMap.cs`

## WorldBiome

Перечисление биомов: поле, редколесье, лес, пляж, озеро, океан, пик, склон.

## Класс карты

При старте смотрит Terrain, режет его на клетки, шумом Перлина раскидывает биомы: по краям океан, внутри озёра/горы/лес. Компонент Terrain в сцене часто **выключен** — игрок видит не heightmap, а runtime-квад `BiomeOverlay` с текстурой биомов ([[RuntimeMaterials]], шейдер `WalkToBiomeUnlit`).

`BiomeTexture` — та же картинка для [[WorldMapUI]].

На материале оверлея `_WalkUvFog = 1`: туман земли считается по UV и расстоянию до камеры (тот же `RenderSettings.fog`, что у зданий). Вершинный туман на одном огромном кваде ломался — серое пятно под игроком.

`Get(клетка)` — какой биом. Вода = нельзя строить (кроме насоса).

Сид мира из [[WorldCatalog]] влияет на шум, поэтому один и тот же сид = похожий ландшафт.
