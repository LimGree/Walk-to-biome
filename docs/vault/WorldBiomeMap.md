# WorldBiomeMap

**Файл:** `Assets/Script/Core/World/WorldBiomeMap.cs`

## WorldBiome

Перечисление биомов: поле, редколесье, лес, пляж, озеро, океан, пик, склон.

## Класс карты

При старте смотрит Terrain, режет его на клетки. Компонент Terrain в сцене часто **выключен** — игрок видит не heightmap, а runtime-квад `BiomeOverlay` с текстурой биомов ([[RuntimeMaterials]], шейдер `WalkToBiomeUnlit`).

Ландшафт — **фаза A** (спека `Генерация_биомов_и_жил_v2.md`):

1. Океан по краю (`edge + wobble < oceanWidth`) — как раньше.
2. Гора и озеро считаются **вместе** и **взаимоисключающе**: клетка горы только если `mScore ≥ lScore`, клетка озера только если озеро выигрывает с запасом `lakeWinMargin`. Семена — только настоящие пики/озёра (score > 0), не больше `maxMountainSeeds` (5). Рост горы узкий (`mountainGrowThreshold` 0.60). Озёрные семена не ставятся ближе `lakeMountainSeparation` к горе.
3. Гора/озеро меньше `mountainMinCells` / `lakeMinCells` откатываются в поле.
4. Если горной площади мало — внутренний offset шума и повтор при том же сиде мира.
5. Склон и пляж — кольца вокруг уже финальных массивов. Пляж не трогает склон.
6. Лес / редколесье / поле заливают оставшееся поле.

`BiomeTexture` — та же картинка для [[WorldMapUI]].

На материале оверлея `_WalkUvFog = 1`: туман земли считается по UV и расстоянию до камеры.

`Get(клетка)` — какой биом. Вода = нельзя строить (кроме насоса).

Озеро (`Lake`) — ходить можно. Океан (`Ocean`) — нельзя: [[PlayerMovement]] не пускает капсулу в клетку океана. Старый сейв посреди океана выталкивает к центру суши.

Картинка земли (`BiomeOverlay`) чуть шире карты (~280 м). Сид мира из [[WorldCatalog]] влияет на шум.

Жилы кладёт отдельно [[WorldResourceScatterer]] поверх уже зафиксированного ландшафта.
