# Conveyor

**Файл:** `Assets/Script/Core/Logistics/Conveyor.cs`  
**Предок:** [[BuildingBase]]

## Зачем нужен

Лента. Предметы едут по ней как вагончики: у каждого есть прогресс 0…1 вдоль **своего** входа. Когда доехал до конца — пытается отдать следующему зданию. Не вышло — ждёт.

Скорость сегмента умножается на [[BeltSpeedSystem.Multiplier]] (общая прокачка лент).

Один объект на клетку, **никогда не пересоздаётся**. Форма — только картинка по соседям, которые смотрят выходом на эту клетку. Выход всегда вперёд (крутится всё здание).

| Соседи на входе | Форма | Префаб |
|---|---|---|
| только сзади, или никого | прямой | `Conveyor_01` |
| один бок, сзади нет | угол (зеркало L/R) | `cornerPrefab` / `Conveyor_Corner` |
| сзади + один бок | T (зеркало на другой бок) | `teePrefab` / `Conveyor_Tee` (`conveer_4_5_model`) |
| два бока, сзади нет | бока | `sidesPrefab` / `Conveyor_Sides` (`conveer_6_model`) |
| сзади + оба бока | три входа | `triplePrefab` / `Conveyor_Triple` (`conveer_3_model`) |

Госты лежат в `Assets/models/Builders/ghost/`. Превью линии берёт ghost-префабы, живая лента — `cornerPrefab` / `teePrefab` / `sidesPrefab` / `triplePrefab`. Масштаб этих префабов не затирается (зеркало угла/T только меняет знак X).

На живом объекте три входа: `StartPoint` (зад), `StartPointLeft`, `StartPointRight`, выход `EndPoint`. Сокеты на визуальных префабах при подстановке снимаются — считает [[BuildingLinker]] по клеткам.

Груз помнит, с какого входа заехал, и едет start → середина → выход. Сейв пишет `entryX/Y`.

## Поля

Список «груза» на ленте: какой предмет, какой прогресс, с какого входа.

## Методы

### Update
Двигает каждый груз вперёд на `скорость × dt × множитель`. Кто доехал — `TryHandoff`.

### TryReceiveItem / TryAcceptTransfer
Принимает, если на ленте есть место. Вход груза считается от соседа, который отдал предмет.

### RefreshShape / Preview
Смотрит соседей сзади/слева/справа и включает нужный меш.

### WriteSave / ReadSave
Список груза, чтобы после загрузки предметы не исчезли с лент и не забыли вход.
