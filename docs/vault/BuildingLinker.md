# BuildingLinker

**Файл:** `Assets/Script/Core/Logistics/BuildingLinker.cs`  
**Тип:** статический класс (объекта на сцене нет)

## Зачем нужен

Кто стоит в клетке и кто кого кормит.

Лента: соседство + `ExitDir`. Станок: клетка, **в которой стоит сокет** (`GetSocketCell`), а не следующая за ним. Сокет часто смещён на ±1 в префабе — стык с лентой в этой клетке, без прыжка через клетку.

## Важные идеи

- `SuppressRelink` — во время загрузки мира здания появляются пачкой. Загрузчик ставит флаг, потом один раз `RelinkAll`.
- `RelinkAround` — пересчитать маски лент вокруг здания (worklist 3×3) и сокеты станков.
- `GetBuildingAt` — кто в клетке.
- `GetSocketCell` — клетка позиции сокета. Если округление ещё на здании (сокет на краю ±0.5) — шаг наружу по forward. Если сокет уже в соседней клетке (±1) — без шага, без прыжка через клетку.
- `FeedsInto` — у ленты по `ExitDir`, у станка если выходной сокет стоит в этой клетке.
- `HasInputFrom` / `AcceptsFromCell` — входной сокет стоит в клетке источника.
- `WorldToCell` — обёртка над сеткой.
