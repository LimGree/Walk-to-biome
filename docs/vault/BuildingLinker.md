# BuildingLinker

**Файл:** `Assets/Script/Core/Logistics/BuildingLinker.cs`  
**Тип:** статический класс (объекта на сцене нет)

## Зачем нужен

Кто стоит в клетке и кто кого кормит.

Лента: соседство + `ExitDir`. Станок: выходной сокет смотрит на клетку входа другого станка (`connectedSocket`). Лента сокетов не имеет — станок отдаёт ей предмет, если клетка перед его выходом занята лентой.

## Важные идеи

- `SuppressRelink` — во время загрузки мира здания появляются пачкой. Загрузчик ставит флаг, потом один раз `RelinkAll`.
- `RelinkAround` — пересчитать маски лент вокруг здания (worklist 3×3) и сокеты станков.
- `GetBuildingAt` — кто в клетке.
- `FeedsInto` — у ленты по `ExitDir`, у станка по forward выходного сокета.
- `HasInputFrom` — лента: источник кормит эту клетку не с фронта. Станок: вход смотрит на источник.
- `WorldToCell` — обёртка над сеткой.
