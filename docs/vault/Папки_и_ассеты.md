# Папки и ассеты без своего C#-класса

Код — не вся игра. Ниже то, что лежит рядом и тоже важно.

## Сцены (`Assets/Scenes/`)

- `MainMenu.unity` — меню
- `Loading.unity` — загрузка
- `SampleScene.unity` — игровой мир
- `3dmodeling.unity` — служебная сцена для моделей, в билд обычно не кладут

## Данные (`Assets/ScriptableObjects/`)

Папки `Builders`, `items`, `recipes`, `Research` — сотни `.asset`. Это экземпляры [[BuildingData]], [[ItemData]], [[RecipeData]], [[ResearchNodeData]]. Каталог-указатель: `Resources/GameDatabase.asset`.

## Модели и префабы

- `Assets/models/` — FBX станков, предметов, жил
- `Assets/models/Builders/ghost/` — гост-модели зданий (в том числе `conveer_3_ghost`, `conveer_4_5_model_ghost`, `conveer_6_model_ghost`)
- `Assets/prefabs/Builders/` — готовые объекты зданий, которые ставятся в мир
- Конвейер: живой `Conveyor_01`; формы `Conveyor_Corner`, `Conveyor_Tee` (T 4/5), `Conveyor_Sides` (два бока), `Conveyor_Triple` (три входа)
- `Assets/images/` — иконки HUD, предметов, исследований

## UI Toolkit

- `Assets/Resources/UI/` — то, что **реально грузится в игре** (uss, tss, шрифт, uxml)
- `Assets/UI Toolkit/` — копии для редактирования в редакторе; их надо синхронизировать с Resources, иначе в билде будет старый стиль

## Звук

`Assets/Resources/Audio/` — папки `ui`, `world`, `buildings`, `music`, `ambient`, `player`. Имена файлов = ключи в [[GameAudio]].

## Шейдеры

- `WalkToBiomeUnlit` — unlit с альфой и опциональным туманом по UV; оверлей биомов, сетка, призраки, голограммы
- `WalkToBiomeSky` — градиентное небо под слайдеры света/тумана [[GameSettings]]
- `WalkToBiomeInvert` — инверт прицела

## Input

`InputSystem_Actions.inputactions` — таблица клавиш, см. [[InputSystem_Actions]].

## Чего в git быть не должно

Папка `Library/` — кэш Unity, сотни мегабайт. В репозиторий не кладут.

## Сейвы игрока

Не в проекте, а в AppData: `.../persistentDataPath/worlds/<id>/save.json`. См. [[WorldCatalog]].
